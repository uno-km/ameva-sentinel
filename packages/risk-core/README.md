# @ameva/sentinel-risk-core

Deterministic Rule Evaluation Engine and Policy Compiler for AMEVA Sentinel.

## Features
- **0~100 Clamped Scoring**: Deterministic, mathematical risk evaluation.
- **Explainable Evidence**: Generates structured, auditable evidence items.
- **Storage Isolation**: Stored event schema isolating raw network internals from browser storage.
- **Fixed-Window Rate Limiting**: In-memory state tracking for burst evaluation.

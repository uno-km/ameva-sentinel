# @ameva/sentinel-browser

Privacy-First Client Telemetry and Interaction Collector for AMEVA Sentinel.

## Features
- **Zero Raw Coordinates**: Collects interaction counts and duration without storing mouse trajectories.
- **Throttled Sampling**: 100ms interval for pointer movements; discrete click/touch events unthrottled.
- **Node.js Fallback**: Safe execution in non-browser testing environments.
